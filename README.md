This repository contains a comprehensive aggregation of all my BlueStamp Engineering projects from 2021 to 2024. Each summer brought new challenges and learning opportunities as I progressed from a rising 7th grader to an incoming sophomore.

1. **IOT Weather Indicator** (2021) - ESP32-based weather display with animated OLED graphics
2. **Phone Controlled Robot Arm** (2022) - Bluetooth-controlled robotic arm with custom Android app
3. **Gesture Controlled Rover** (2023) - Accelerometer-controlled robot car with wireless communication
4. **Ball Tracking Robot** (2024) - Computer vision robot using Raspberry Pi and OpenCV
